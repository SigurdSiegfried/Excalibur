Excalibur
Your games, apps, videos and photos — and your whole PC — in one place.
Created by Sigurd, built together with Claude (Anthropic's AI).

Download
Get Excalibur Setup.exe from the latest release on the right (under Releases), run it and press Install.
No admin rights needed. Windows may say "Windows protected your PC" because Excalibur is new and not signed yet — click More info > Run anyway.

Works on
Windows	Supported	Notes
Windows 11	✅ Yes	Everything works.
Windows 10 (22H2 recommended)	✅ Yes	Everything works except a few Windows 11-only switches: taskbar left/centre and Remove Copilot. Efficiency mode is a little weaker.
Windows 8 / 7	❌ No	Microsoft no longer supports the WebView2 component Excalibur needs.
Needs: Microsoft Edge WebView2 Runtime (already on most PCs; Excalibur offers the free download if it's missing).

Updating
Excalibur checks this page twice a day and shows an Update now bar when there's a new version.
Or go to Settings > Updates > Check now:

🟢 Green – you're up to date
🟡 Yellow – a new version is ready
🔴 Red – the check didn't work
Help
A full guide with tips and known issues is built in: Settings > Guide & known issues, or Start > Excalibur Guide.
