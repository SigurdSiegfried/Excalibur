#Excalibur 2.0 Update 13.3
Your games, apps, videos and photos — and your whole PC — in one place.
Created by Sigurd, built together with Claude (Anthropic's AI).
Download
Get Excalibur Setup.exe below (under Assets), run it and press Install — or Update if you already have Excalibur. Your settings are kept.
No admin rights needed. Windows may say "Windows protected your PC" because Excalibur is new and not signed yet — click More info > Run anyway.
What's new in 13.3
Google apps and Android games
Google apps in the app sidebar (Apps tab): Google Messages (your Android phone's texts — pair it once with a QR code), Drive, Photos, Calendar, Maps, Keep, Docs, Meet and YouTube Music. One Google sign-in covers them all, plus YouTube and Gmail.
Android games: install Google Play Games (Apps > Get apps & browsers) and its games show up in your Games tab.
Fits any screen
Interface size: Auto (Settings > Themes & look) — Excalibur scales itself to your screen: 1080p laptops, 1440p, 4K and any Windows scaling. Or pick a size yourself (70–150%).
The web apps, docked apps and Game Dock games inside Excalibur scale and fit the same way.
The top bar tightens up on smaller windows instead of running off the edge.
Scroll bars on every page, menu and panel — wide, in your theme's colour, never hidden under the app strip. Page Up / Page Down / Home / End scroll too.
New looks
Four styles, each its own HUD: Excalibur Classic, New Excalibur (side menu, gold frames), Spartan HUD and Recon Grid.
New themes with their own icons: Field Ops and Graphite Recon.
A new installer screen.
Fixes
FanControl is found wherever it's installed. If not, Settings > Fans has Check again and Find FanControl…
Updates: the version inside Excalibur matches the release, so it no longer keeps offering the same update.
Settings always go back to the page with all the tiles.
Settings are saved safely — a PC crash can no longer reset them.
DLSS 5 Manager opens on top of Excalibur, even in full screen.
Works on
Windows	Supported	Notes
Windows 11	✅ Yes	Everything works.
Windows 10 (22H2 recommended)	✅ Yes	Everything works except a few Windows 11-only switches: taskbar left/centre and Remove Copilot. Efficiency mode is a little weaker.
Windows 8 / 7	❌ No	Microsoft no longer supports the WebView2 component Excalibur needs.
Needs: Microsoft Edge WebView2 Runtime (already on most PCs; Excalibur offers the free download if it's missing).
Updating
Excalibur checks this page twice a day and shows an Update now bar when there's a new version.
Or go to Settings > Updates > Check now:
🟢 Green – you're up to date
🟡 Yellow – a new version is ready
🔴 Red – the check didn't work
Settings > About shows your version and build.
Good to know
Excalibur isn't code-signed yet. Windows may show a SmartScreen warning or scan it the first time you run it. That's normal for new, unsigned programs.
Fans, lighting, sound presets and graphics boost use free helper apps you install yourself (FanControl, OpenRGB, Equalizer APO, DLSS 5 Manager). The guide shows how to set each one up.
Found a bug? Settings > Diagnostics > Open diagnostics & fix finder, then Export and send the zip with a short description of what happened.
Help
A full guide with setup steps, tips and known issues is built in: Settings > Guide & known issues, or Start > Excalibur Guide.
